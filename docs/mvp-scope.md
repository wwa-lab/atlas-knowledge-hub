# MVP Scope

The MVP is a lightweight internal demo and workflow definition. It proves the product shape without committing to production infrastructure.

## In Scope

- Static prototype.
- Knowledge Space page.
- Document, Wiki, Graph, Review, and Ask tabs.
- Mock batch status.
- Mock file tree.
- Mock Wiki content.
- Mock graph.

## Out Of Scope

- Authentication.
- Real OCR engine.
- Real RAG.
- Production database.
- Complex permission system.
- External cloud integrations.
- Real company document ingestion.

## Acceptance Shape

The MVP should help stakeholders understand the end-to-end flow:

1. A project creates a Knowledge Space.
2. A document package becomes a batch.
3. Files move through conversion and parsing states.
4. Markdown is normalized and reviewed.
5. Approved pages become Wiki and graph content.
